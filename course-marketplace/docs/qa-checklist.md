# Проверка проекта

## Автоматические проверки
- Backend: Vitest unit — права управления курсами, токены, пагинация.
- Frontend: Testing Library — карточка курса, пустой список, заголовок страницы.
- CI: TypeScript strict, тесты, сборка клиента, сборка контейнеров.

## Ручные интеграционные сценарии (не заменяют автоматические интеграционные тесты)
1. Вход студента → запись → прохождение урока → отзыв.
2. Вход преподавателя → создание курса → добавление урока → отправка на модерацию.
3. Вход модератора → публикация курса → управление ролями → блокировка пользователя.
4. Проверка запрета чужих операций: ученик не может создавать курсы; преподаватель не может редактировать чужие.
5. Проверка форматов загрузки (JPG, PNG, WEBP, PDF, до 5 МБ).
6. Просмотр на ширинах 360, 768, 1280, 1920 px.

**Важно:** требование практики об интеграционных API-тестах с тестовой БД и 60% покрытии сервисов требует отдельной реализации и проверки. Не заявляйте прохождение этих требований без фактических результатов. Публичный деплой также выполняется отдельно.
